CodeLens 本机工作台

在自己的电脑上导入项目、查看代码结构并生成审查报告。

下载 CodeLens

  1. 安装 Python 3.11 或以上版本，并完整解压下载的 ZIP。
  2. 在解压目录打开终端并设置 CODELENS_LOCAL_DATABASE_URL，指向本机 PostgreSQL 数据库。Windows 运行 py -3 start-local.py，macOS 或 Linux 运行 python3 start-local.py。
  3. 依赖安装完成后，在浏览器打开 本机工作台。

项目、历史记录和模型设置保存在你的设备上。启用 AI 审查时，本机工作台会将所需源码直接发送到你配置的模型服务。
