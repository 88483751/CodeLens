# CodeLens 上云 · 零基础图文操作手册

适用对象：第一次用阿里云、第一次部署项目。
前置状态（已完成，不用再动）：实例 `ecs.e-c1m2.large`，2 核 4 GB，Windows Server 2022，公网 IP **121.41.29.215**，状态「运行中」。
预计耗时：25 分钟左右，其中约 10 分钟是等下载，你可以离开。

---

## 先搞懂 4 个名词（30 秒）

| 名词 | 通俗解释 |
|---|---|
| ECS 实例 | 阿里云帮你开着的一台电脑。你付的钱就是这台电脑的"开机费"。 |
| 公网 IP | 这台电脑在互联网上的门牌号，你这台是 `121.41.29.215`。 |
| 远程桌面 | 在你自己电脑上开一个窗口，窗口里显示的是那台服务器的桌面，你可以像操作自己电脑一样操作它。 |
| 端口 / 安全组 | 端口是"门牌号后面的房间号"。网站默认走 80 号房，我们改用 **8080** 号房（80 需要备案，8080 不用）。安全组就是阿里云机房门口的保安，不登记的房间号他一律不放人进来，所以必须手动登记 8080。 |

**整个过程只做三件事：把项目文件搬进服务器 → 在服务器上跑一个安装脚本 → 告诉保安放行 8080。**

---

## 第 1 步：在自己电脑上，把项目打包（约 2 分钟）

这一步在**你自己的电脑**上做，不在服务器上。

1. 按 `Win + R`，输入 `powershell`，回车，打开蓝色窗口。
2. 粘贴下面这行，回车（作用是进入项目目录）：
   ```powershell
   cd "C:\Users\QWER1\Desktop\创新创业实践\CodeLens"
   ```
3. 再粘贴这行，回车（作用是打包）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File deploy\windows\pack.ps1
   ```
4. 窗口会滚动一大段前端构建的文字，**这是正常的，不要关窗口**。等它不再滚动、出现 `[3/3] Done.` 和绿色的 `Package : ...codelens-release.zip` 就完成了。
5. 回到你的**桌面**，应该多了一个 **`codelens-release.zip`**，大小约 0.5 MB。

> **如果报错**：提示找不到 `npm`，说明你本机 Node.js 没装好，先确认项目在你本机能正常启动。提示找不到文件，说明第 2 步的目录没进对，重新执行第 2 步。

---

## 第 2 步：连上服务器的桌面（约 2 分钟）

1. 在自己电脑上按 `Win + R`，输入 **`mstsc`**，回车。这就是 Windows 自带的"远程桌面连接"。
2. 「计算机」一栏填 **`121.41.29.215`**，先**不要急着点连接**。
3. 点左下角「**显示选项**」→ 切到「**本地资源**」选项卡 → 点「本地设备和资源」下面的「**详细信息**」→ 勾选「**驱动器**」和「**剪贴板**」→ 确定。
   *（这一步很关键，勾了之后才能把文件复制进服务器。）*
4. 回到「常规」选项卡，点「**连接**」。
5. 弹出登录框：用户名 **`Administrator`**，密码填你买实例时设置的那个 Windows 密码 → 确定。
6. 可能提示"证书不受信任"，点「**是**」继续。
7. 稍等十几秒，你会看到一个**全新的 Windows 桌面**——这就是那台服务器。

> **不知道密码 / 登录失败**：回到阿里云控制台这个实例页面，点上面的「**重置密码**」按钮 → 设置新密码（要含大写字母、小写字母、数字）→ 按提示**重启实例** → 等 2 分钟再重新连接。
>
> **连不上、一直转圈**：通常是安全组没放行远程桌面的 3389 端口。按第 5 步的同样方法，再加一条端口范围填 `3389/3389` 的入方向规则即可。也可以改用控制台里的「**远程连接**」蓝色按钮，选 Workbench，在浏览器里直接操作服务器，但 Workbench 传文件不如远程桌面方便。

---

## 第 3 步：把打包好的文件搬进服务器（约 1 分钟）

1. 在自己电脑桌面，右键 `codelens-release.zip` → **复制**（或 Ctrl+C）。
2. 切换到远程桌面窗口，在服务器里打开「**此电脑 → 本地磁盘 C:**」。
3. 在 C 盘空白处 **Ctrl+V** 粘贴。文件只有 0.5 MB，几秒就好。
4. 确认服务器上存在 **`C:\codelens-release.zip`**。

---

## 第 4 步：在服务器上跑安装脚本（约 8–15 分钟，主要是等）

这一步会自动装好所有环境，你不需要懂它每一步在干嘛。

1. 在**服务器的桌面**上，点左下角开始菜单，输入 `powershell`。
2. 在「Windows PowerShell」上**点右键 → 以管理员身份运行**。弹窗问"是否允许更改"，点「**是**」。
   *（必须管理员，否则装不了软件、开不了防火墙。）*
3. 在打开的蓝色窗口里，粘贴第一条命令，回车：
   ```powershell
   Expand-Archive C:\codelens-release.zip C:\codelens-pkg -Force
   ```
   *（把压缩包解开到 C:\codelens-pkg，几秒就好。）*
4. 再粘贴第二条命令，回车：
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\codelens-pkg\deploy\windows\setup.ps1
   ```
5. 接下来脚本会自动做这些事，每步前面都有 `==>` 开头的提示：

   | 提示 | 在干什么 | 大概多久 |
   |---|---|---|
   | `Copying sources` | 把代码放到 `C:\codelens\app` | 几秒 |
   | `Downloading Python` | 从国内镜像下载 Python 安装包 | 半分钟 |
   | `Installing Python` | 静默安装 Python | 1 分钟 |
   | `Installing backend dependencies` | 下载项目依赖（最久的一步） | 3–8 分钟 |
   | `Checking nginx` | 装网站服务器 nginx | 半分钟 |
   | `Registering auto-start` | 设置开机自动启动，以后重启服务器不用管 | 几秒 |
   | `Health check` | 自己检查网站通不通 | 最多 40 秒 |

6. **成功的标志**：最后出现
   ```
   API  127.0.0.1:18766  healthy = True
   WEB  127.0.0.1:8080   healthy = True
   ```
   两个都是 `True` 就装好了。如果是 `False`，把窗口里最后 30 行复制发给我。

> **中途远程桌面断了 / 窗口被关了**：重新连上服务器，用管理员 PowerShell 把第 4 步的第二条命令**再跑一遍**即可，脚本支持重复执行，不会搞坏东西。

---

## 第 5 步：告诉阿里云"放行 8080"（约 2 分钟，不做就外网打不开）

1. 回到**你自己电脑的浏览器**，打开阿里云 ECS 控制台的这个实例页面（就是你截图那一页）。
2. 点中间那排标签里的「**网络与安全组**」。
3. 页面上会列出安全组，点「**配置规则**」（或点安全组的蓝色 ID 进去，再选「入方向」）。
4. 点「**手动添加**」，按下面填：

   | 输入框 | 填什么 |
   |---|---|
   | 授权策略 | 允许 |
   | 优先级 | 1（默认即可） |
   | 协议类型 | 自定义 TCP |
   | 端口范围 | **`8080/8080`** |
   | 授权对象 | **`0.0.0.0/0`**（意思是任何人都能访问这个网站） |
   | 描述 | CodeLens |

5. 点「**保存**」。**立即生效，不用重启。**

---

## 第 6 步：打开你的网站

在自己电脑的浏览器地址栏输入（注意是 `http`，不是 `https`，结尾有斜杠）：

```
http://121.41.29.215:8080/
```

看到 CodeLens 的界面就成功了。随便导入一个项目文件夹试一次分析，确认功能正常。

把这个网址发给同学或老师，他们也能打开——这就是"部署到公网"。

## 遇到问题怎么办

| 你看到的情况 | 最可能的原因 | 怎么办 |
|---|---|---|
| 浏览器一直转圈，最后"无法访问此网站" | 第 5 步安全组没加，或加错了端口 | 回第 5 步，确认端口是 `8080/8080`，方向是**入方向** |
| 浏览器显示 502 Bad Gateway | 后端没起来 | 服务器上管理员 PowerShell 执行 `Start-ScheduledTask CodeLensAPI`，等 30 秒再刷新 |
| 页面能打开，但一点分析就报"只允许本机访问" | nginx 配置没生效 | 把 `C:\codelens\nginx\conf\nginx.conf` 发我 |
| 第 4 步卡在下载依赖很久 | 网络慢 | 耐心等，脚本已用国内镜像；超过 15 分钟就把窗口最后几行发我 |
| 重启过服务器后网站打不开 | 计划任务没自启 | 服务器上执行 `Start-ScheduledTask CodeLensAPI; Start-ScheduledTask CodeLensWeb` |

**排错时最有用的两个文件**（在服务器上，用记事本打开即可）：
- `C:\codelens\logs\codelens.log` —— 后端日志
- `C:\codelens\nginx\logs\error.log` —— 网站服务日志
